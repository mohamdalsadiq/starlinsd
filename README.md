# مدير Starlink — الاشتراكات والاختصارات

تطبيق Android محلي بالعربية مبني بـ Kotlin وJetpack Compose وRoom. فرع `feat/subscription-shortcuts` يحوّل التطبيق من فحص الشبكة إلى تسجيل الاشتراكات وإدارة الوقت والإيراد والاختصارات.

**التطبيق لا يكتشف المتصلين فعليًا ولا يفصل الإنترنت.** تبدأ الجلسة عند التسجيل اليدوي أو نجاح استبدال الاختصار؛ عند انتهاء الوقت يذكّرك التطبيق بمراجعة الاتصال وفصله من الراوتر. إيقاف الوقت داخل التطبيق لا يوقف اتصال الإنترنت.

## الاستخدام

1. افتح **الباقات** واضبط المدة والسعر كاش وبنكك. الباقات الافتراضية: ساعة بـ500 كاش / 625 بنكك، و3 ساعات بـ1000 / 1250، وأهل البيت مجانًا. المبالغ بالجنيه السوداني وقابلة للتعديل.
2. من **الإعدادات** فعّل الإشعارات والمنبّهات الدقيقة، ثم اختر التطبيقات المسموحة وفعّل خدمة الاختصارات في إمكانية الوصول.
3. سجّل المشترك بزر **تسجيل اشتراك**، أو اكتب `س3/محمد` ثم مسافة داخل تطبيق مسموح. استخدم `_` بين أجزاء الاسم، مثل `س1/محمد_أحمد`. `بيت/أحمد` يسجّل باقة البيت دون إيراد. نجاح التوسع يبدأ الوقت حتى لو لم ترسل الرسالة.
4. تابع المشتركين وابحث عنهم، أوقف الوقت مؤقتًا أو استأنفه أو أنهِ الاشتراك مبكرًا. السجل يحتفظ بالتاريخ والسعر.
5. أدخل فاتورة Starlink بالدولار وسعر الدولار **ببنكك** وبداية الدورة وآخر يوم فيها والمصروفات المكافئة للكاش؛ تعرض الرئيسية صافي الدورة والمدة المتبقية.
6. صدّر السجل بصيغة JSON للأرشفة. يشمل التصدير بيانات الأجهزة القديمة. الاستيراد غير منفذ في هذه الدفعة.

## قواعد الحساب

- بعد 30 دقيقة **استخدام محسوب** افتراضيًا يُثبّت كامل سعر الباقة مرة واحدة. المدة قابلة للتعديل للاشتراكات الجديدة. الباقة الأقصر من المهلة تُثبّت عند نهايتها.
- لا يُحسب وقت الإيقاف المؤقت. الإلغاء قبل التثبيت دون إيراد؛ الإلغاء بعده يحتفظ بالإيراد. أهل البيت دائمًا بلا إيراد.
- الاشتراك يحتفظ بنسخة من سعره ومهلة التثبيت ونسبة بنكك وقت تسجيله؛ تغيير الإعدادات لا يعيد تسعير القديم.
- عند زيادة بنكك 25٪: 1250 بنكك مكافئ 1000 كاش. تُعرض المبالغ الخام منفصلة ويُجمع الدخل بالقيمة المكافئة للكاش. الزيادة ليست ربحًا إضافيًا.
- الصافي = إيراد الدورة المكافئ للكاش − تكلفة فاتورة الدورة كاملة مكافئة للكاش − المصروفات المدخلة. هذا تقرير تشغيلي تقديري، ولا يتتبع الديون أو التحصيل الفعلي.
- تاريخ التثبيت يُنسب إلى لحظة بلوغ المهلة ولو كان التطبيق مغلقًا، ولا يتكرر بعد إعادة فتحه. المؤقت يعتمد على وقت الهاتف؛ تغييره يدويًا يؤثر في المدة.

## الاستمرارية والخصوصية

لا توجد خدمة فحص مستمرة. تستخدم المواعيد `AlarmManager` مع استعادة من قاعدة البيانات عند إعادة تشغيل الهاتف أو تحديث التطبيق أو تغيير الوقت أو منح إذن المنبّهات. عند منع الإذن الدقيق تستخدم تنبيهات غير دقيقة قد تتأخر. الإيقاف الإجباري وقيود الشركات المصنعة وإلغاء الأذونات قد يمنع التنبيهات؛ افتح التطبيق وراجع حالة الجاهزية.

خدمة الاختصارات تتعامل فقط مع حقل قابل للتحرير وله التركيز في تطبيق اخترته، وتتجاهل كلمات المرور وتوسّع بعد مسافة أو سطر جديد مع حفظ موضع المؤشر وبقية النص. بعض المحررات لا تدعم استبدال النص عبر إمكانية الوصول. لا ترسل الخدمة النصوص لخادم. النسخ الاحتياطي للنظام يخضع لإعدادات Android؛ ملف التصدير يحتوي أسماء وسجلاتك، فاحفظه في مكان تختاره.

## البناء والتحقق

المتطلبات: **JDK 21** وAndroid SDK 36 وBuild Tools 36.0.0. Robolectric 4.16.1 يتطلب Java 21 لاختبارات Android 16 / SDK 36. Wrapper يثبت Gradle 9.3.1 مع SHA-256.

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

أضف `-Proborazzi.test.record=true` للأمر لحفظ صورة اللوحة من اختبار الواجهة. CI يفعل ذلك تلقائيًا ويضع الصورة ضمن تقارير التحقق.

مخرج APK: `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions يحفظ APK بعد نجاح البوابات وتقارير الاختبارات وLint. اختبارات الجهاز المتصل منفصلة:

```sh
./gradlew :app:connectedDebugAndroidTest
```

اختبارات هذه الدفعة تشمل قواعد المال والوقت، الإلغاء والإيقاف المؤقت، ثبات السعر، منع التكرار، ترحيل قاعدة v1 الفعلية مع تحقق Room، وواجهة محرر الاختصار. راجع آخر نتيجة CI في طلب الدمج قبل اعتبار البناء ناجحًا.

## نسخة التجربة والتحديث الآمن

نسخة `debug` اسمها «مدير Starlink — تجربة» ومعرّفها ينتهي بـ`.preview`، لتثبت بجانب تطبيقك الحالي ببيانات مستقلة. لا تنقل بيانات النسخة الأصلية تلقائيًا. CI يولّد مفتاح تجربة جديدًا؛ الإصدارات التجريبية المختلفة قد لا تُثبت فوق بعضها.

نسخة `release` تحافظ على معرّف التطبيق الأصلي `com.aistudio.starlinkmanager.zbxpq`. يتطلب التحديث الذي يحفظ البيانات مفتاح التوقيع المطابق للنسخة المثبتة؛ لم يتم إعداد مفتاح إنتاج جديد أو تغييره. لا تحذف التطبيق الأصلي لتجاوز اختلاف التوقيع. ترحيل Room من v1 إلى v2 يحتفظ بجدولي الأجهزة والاختصارات ولا يستخدم المسح التلقائي.
