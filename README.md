# مدير Starlink

تطبيق Android لإدارة مؤقتات اشتراكات الأجهزة المكتشفة في الشبكة المحلية، مع اختصارات نصية عبر Accessibility. مبني باستخدام Kotlin وJetpack Compose وRoom.

**المؤقت لا يفصل الإنترنت عن الجهاز.** لا يوجد تكامل تحكم مع Starlink في هذه النسخة. فحص ping يعرض الأجهزة التي استجابت للفحص ولا يضمن عرض كل العملاء المتصلين.

## البناء والتحقق

المتطلبات: JDK 17، وAndroid SDK Platform 36، وBuild Tools 36.0.0. عيّن `ANDROID_HOME` إلى مسار SDK أو اضبط `sdk.dir` في `local.properties` غير المتتبع.

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

على Windows استخدم `gradlew.bat`. ينزّل Wrapper إصدار Gradle 9.3.1 ويتحقق من SHA-256 للتوزيعة. يحتاج التشغيل الأول إلى اتصال بمستودعات Google وMaven Central وGradle Plugin Portal.

المخرج عند نجاح البناء: `app/build/outputs/apk/debug/app-debug.apk`.

لتشغيل الاختبار الذي يحتاج هاتفًا أو Emulator متصلًا:

```sh
./gradlew :app:connectedDebugAndroidTest
```

CI يشغّل Unit tests وLint والبناء، ويحفظ تقارير التحقق حتى عند الفشل. الاختبارات على جهاز حقيقي ليست ضمن CI الحالي.

## توقيع التحديثات

يحافظ المشروع على `applicationId` الحالي. لا تغيّره لتجاوز مشكلة تثبيت تحديث. Workflow الحالي يولّد مفتاح debug جديدًا لكل تشغيل؛ لذلك لا تضمن نسخ CI قابلية التحديث فوق APK قديم. يلزم إعداد مفتاح توقيع ثابت قبل اعتماد توزيع منتظم، مع الحفاظ على المفتاح الذي وقّع النسخة الموجودة إن كان متاحًا. لا تحذف التطبيق لإجبار التثبيت قبل حفظ بياناته.
